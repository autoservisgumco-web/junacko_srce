# Јуначко срце — мобилна PWA апликација

Ова је засебан мобилни прототип у оквиру репозиторијума `junacko_srce`.

## Отварање
Када GitHub Pages објави измене, апликација је доступна на:
https://autoservisgumco-web.github.io/junacko_srce/mobilna-aplikacija/

## Инсталација на телефону
Отвори адресу у Chrome-у на Android-у, па изабери „Install app“ или „Add to Home screen“.

## Садржај
- `index.html` — кликабилни мобилни интерфејс са три главне целине
- `manifest.webmanifest` — PWA подешавања
- `sw.js` — основни offline cache
- `icon.svg` — иконица

## Напомена
Образац „Укључи се“ је тренутно демонстрациони и не шаље податке. За пријем пријава потребно је повезати га са имејлом или backend-ом. Биографски текстови су почетни нацрт и треба их допунити аутентичним причама, фотографијама и материјалима.
